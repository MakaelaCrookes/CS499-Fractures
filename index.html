Makaela Crookes, Jasmine Flowers

Implementation Plan

Our original implementation planned to use the same dataset [1] as the project that inspired our own. Building on the original project to refine and strengthen the original creation.

Challenge

When we began the training of our models we realized that the 15GB dataset was way too large for the scale of our project.

Actual Implementation

To address the dataset size issues of our original implementation plan we did further research to find an appropriately sized dataset [2] that matched the scale of our project. Doing so also allowed us to find a dataset more geared towards our goals as the new dataset did not have a pure focus on wrist fractures. Our intentions with our implementation were to expand the models ability to assess fractures without being limited to wrist specialization.

How To Run

  1. Download FracAtlas Dataset

  2. Clone The Github Repository [GitHub]

  3. Create a Virtual Environment

    4. python -m venv venv source venv/bin/activate


  4. Install Dependencies

    5. pip install -r requirements.txt


  5. Run ResNet18 Training First

    6. python 02_train_resnet.py


  6. Train ViT

    7. python 03_train_vit.py
